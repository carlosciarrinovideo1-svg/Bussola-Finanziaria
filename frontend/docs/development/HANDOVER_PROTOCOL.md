# Handover Protocol

## Obiettivo

Permettere a una nuova sessione di riprendere il progetto senza ricostruire manualmente il contesto.

## Informazioni necessarie

La sessione successiva deve trovare:

- stato repository;
- ultimo sprint completato;
- sprint corrente;
- obiettivo;
- vincoli;
- prossime azioni.

## Regola

Richiedere codice aggiuntivo solo quando indispensabile per implementare lo sprint corrente.
