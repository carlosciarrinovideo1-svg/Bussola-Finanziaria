# Bussola Development System (BDS)

## Obiettivo

Il Bussola Development System definisce il processo operativo per mantenere continuità nello sviluppo di Bussola Finanziaria.

## Principi

- Il repository rappresenta la verità tecnica.
- La documentazione di continuità rappresenta la verità operativa.
- Ogni sprint ha un solo obiettivo.
- Ogni modifica deve essere minima e verificabile.
- Ogni sprint termina con verifica, commit, push e aggiornamento documentazione.

## Fonti operative

### Repository

Contiene:

- codice;
- configurazioni;
- stato tecnico reale.

### Documentazione continuità

Contiene:

- obiettivi correnti;
- decisioni;
- vincoli;
- prossimo lavoro.

## Regola principale

La nuova sessione non deve ricostruire il progetto.

Deve leggere lo stato disponibile, identificare lo sprint corrente e procedere con lo sviluppo.
